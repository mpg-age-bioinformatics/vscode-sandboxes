If macOS blocks this location

First allow folder access if macOS prompts, or check System Settings → Privacy & Security → Files and Folders. If this app is absent and access remains blocked, you may need to add the installed VS Code - Docker Sandboxes app under Full Disk Access using +, enable it, then quit and reopen the app. Full Disk Access grants broader access to the launcher and its host helpers. If macOS offers access to specific folders, choose only your project folder.

Apple’s folder permission guidance
